# LevelForge 部署与使用说明
---

## 0. 这个工具能帮你做什么

在自己电脑上跑一个网页工具，它能：

1. **自动出关卡**——你告诉它"要一关标准难度、带 3 只鸭子"，它让 AI 设计一关；
2. **自动检查能不能通关**——生成后马上验算，通不了的自动重来；
3. **直接把关卡存成文件**——存进你的游戏工程，格式就是游戏原本用的格式。

你不需要联网服务器、不需要数据库、不需要装开发工具。

---

## 1. 准备

| 要准备的 | 说明 |
|---|---|
| 一个 AI 服务的账号 | 推荐 DeepSeek（便宜、方便）。注册后要创建一个"API Key"，第 4 步教你怎么拿 |

---

## 2. 安装（只需做一次，约 5 分钟）

1. 把压缩包**解压**到一个固定位置，例如 `D:\LevelForge`
   （不要放在桌面或下载文件夹里，容易被清理）
2. 打开解压出来的文件夹，**双击 `start.cmd`**
3. 如果 Windows 弹出蓝色提示"已保护你的电脑"：
   点 **更多信息 → 仍要运行**（这是自己电脑上的正常提示）
4. 会出现一个**黑色窗口**，过几秒**浏览器自动打开**一个网页
   - 看到标题是 LevelForge 的界面 = 安装成功
   - 如果浏览器没自动打开：手动打开 Edge 或 Chrome，在地址栏输入 `http://localhost:5000` 回车
5. **黑色窗口不要关**——它就是工具本体，关掉就等于关闭工具

**建议**：右键 `start.cmd` → **发送到 → 桌面快捷方式**，以后从桌面双击即可。

> 工具不给电脑装任何东西，也不会开机自启；不想要了直接删掉整个文件夹即可。

---

## 3. 先认识界面（30 秒）

打开后，页面顶部是这样的：

- 左上角：**玩法下拉框**（当前在做哪个游戏）
- 右边：**＋ 导入项目** 按钮
- 四个页签：**工作台 · 批量 · 接入向导 · 设置**

下面按顺序用一遍：设置 → 接入向导 → 工作台。

---

## 4. 填写 AI 模型（第一次必须做，约 5 分钟）

1. 点顶部 **设置**
2. 在"LLM API"区域，点一下 **DeepSeek** 这个快速填充按钮
   → "地址"和"模型"会自动填好（不填快速按钮也可以手填）
3. 填 **API Key**（关键的一步）：
   - 打开 <https://platform.deepseek.com> → 注册 / 登录
   - 左侧菜单点 **API keys** → **创建 API key** → 复制那一长串字符
   - 回到工具，粘贴到"API Key"输入框（粘贴进去会显示成圆点，正常）
4. 点 **保存**，再点 **测试连接**
   - 出现绿色 **"✓ 连接成功"** = 配置完成
   - 出现红色失败：先检查 Key 有没有复制完整、账号里有没有余额；还不行就换"智谱 GLM"再试

> 其余几栏（超时、预算）**保持默认即可**，不用改。

---

## 5. 让工具认识你的游戏（生成"适配层"，约 15 分钟）

**先解释一个词**：适配层 = 一段小程序，作用是"把游戏的规则讲给工具听"。工具会用 AI 自动写这段程序，你不用懂代码。

### 5.1 导入项目

1. 点右上角 **＋ 导入项目**
2. 弹出窗口里有一个"**项目目录（绝对路径）**"输入框：
   - 打开文件资源管理器，进到你的游戏工程文件夹（能看到 `Assets` 或 `assets` 那一层）
   - 点一下窗口上方的**地址栏**，复制那串路径（例如 `E:\Projects\MyGame`）
   - 粘贴到输入框，点 **识别并导入**
3. 页面会**自动跳到"接入向导"**

### 5.2 向导1——登记

- 页面上会出现几个"关卡根目录候选"，选一个（**选 JSON 文件最多的那个**），点 **保存关卡根目录**
  （如果一个候选都没有，就在输入框里手动填你的关卡文件夹路径，再点保存）
- 下面"玩法代码根目录候选"同样选一个，点保存（这步影响 AI 看懂规则的准确度，建议选）
- 不知道选哪个也没关系，选错可以回来改

### 5.3 向导2——资格评估（可跳过）

- 点 **开始深度分析（调用设置页的模型）**，等 30 秒~2 分钟，等文本框里出现分析结果后点 **存档并完成**
- 不想等就直接点 **标记受阻（未提供报告）**，后面照样能生成

### 5.4 向导3——生成适配层（核心一步）

- 点 **生成适配层（平台内自动）**
- 等 **3~10 分钟**，**期间不要关页面**
- 成功标志：页面出现 **"适配层已生成并通过门1 ✓"**（顶部玩法名后面的状态也会跟着变）
- 失败了：点 **重新尝试平台内生成** 再来一次；连续失败 2 次就把报错截图发给维护的人

### 5.5 向导4、5、6

这三步是"正式上线前"才需要的验收，**现在可以不管**。

---

## 6. 生成第一关（以现有的 IAP猪了个猪 项目为例）（约 1 分钟）

1. 点顶部 **工作台**
2. **难度**：选 `1 · 轻松` / `2 · 标准` / `3 · 烧脑`
3. **关卡编号**：填一个数字，例如 `501`（导出的文件名就是它，比如 `000501.json`）
4. **特殊要求**：可以留空。想指定内容就这么写：
   - `至少包含 3 只土豪猪`
   - `至少包含 10 只爆炸猪`
5. 点 **生成**，等几十秒到几分钟（页面会显示进行到哪一步）
6. 右边出现结果后，点缩略图可以**看关卡样子和解法回放**
7. 满意就点 **采纳落盘** → 弹窗里点 **确认落盘**
   → 提示 **"已落盘：……\000501.json"** 就成功了
   不满意就点 **再次生成**，多试几次会得到不同的关卡

> 只想先看看效果、暂时不接自己的游戏？顶部下拉选 **PiggyFarm（经典模式）**，照样能生成，
> 生成后不点"采纳落盘"，改点 **下载 JSON** 存到任意文件夹即可。

---

## 7. 一次生成一大批（批量页）

1. 点顶部 **批量**
2. **起始编号** 501、**结束编号** 510（这样是 10 关）
3. 三个难度各填数量，**三个数加起来必须等于 10**（页面会实时提示"还差/超出"）
4. 有统一要求就填"统一特殊要求"，没有就留空
5. 点 **开始批量生产**
   - 后台排队执行，**关掉网页也不影响**，回来还能看到进度
6. 全部跑完后：
   - 点每个格子可以看预览
   - **批量入库（N 关）**：把成功的关卡一次性写进关卡目录
     （如果之前已有同编号文件，先勾上"覆盖同编号旧文件"）
   - **导出 JSON**：只下载，不写目录
   - 有关卡失败，可以点 **重试失败关（N）**

---

## 8. 关卡文件去哪了 / 怎么进游戏

- 用"采纳落盘"：文件写进你在 **5.2 步骤①** 里设置的那个"关卡根目录"，
  文件名一般是编号（PiggyFarm 会补零成 `000501.json`；**以落盘弹窗里"目标路径"那一行为准**）
- 用"下载 JSON"：文件进了浏览器的**下载文件夹**
- 把文件放进游戏工程对应的关卡目录 → 重新打包游戏 → 游戏里就能看到新关卡

---

## 9. 日常使用就三步

1. 双击桌面上的 `start.cmd`
2. 浏览器打开后点 **工作台**
3. 选难度 → 点 **生成** → **采纳落盘**

---

## 10. 数据在哪 / 怎么搬家 / 怎么卸载

- 所有数据（关卡库、设置、AI 配置、历史记录）都在工具文件夹里的 **`data`** 子文件夹
- **换电脑**：关掉工具 → 把整个文件夹拷到新电脑 → 双击 `start.cmd`，数据原样还在
- **卸载**：关掉黑色窗口 → 删掉整个文件夹。不去系统里留任何东西

## 11. 常见问题

| 现象 | 怎么办 |
|---|---|
| 双击 `start.cmd` 一闪而过 / 没反应 | 右键 → 以 **管理员身份运行** 试一次；还是不行就看黑窗口里的红字，截图发给维护的人 |
| 浏览器显示"无法访问此网站" | 黑窗口还开着吗？地址是不是 `http://localhost:5000` |
| 页面打不开，黑窗口里有 `address already in use` | 5000 端口被别的程序占了：关掉那个程序，或重启电脑后再双击 `start.cmd` |
| "测试连接"失败 | Key 是否复制完整（不要带空格）、账号是否充值、模型名是否写错；换"智谱 GLM"再试 |
| 生成总是失败 | 展开"高级选项"，把 **候选上限** 从 3 调到 6 再试；或换简单一点的难度 |
| 采纳时提示"编号冲突" | 说明这个编号已经有文件了，点 **确认替换** 覆盖，或换一个编号 |
| 找不到"采纳落盘"按钮 | 要等生成**成功**后才会出现 |
| 界面一片空白 | 用最新版 Edge 或 Chrome；按 `Ctrl + F5` 强制刷新 |
| AI 花了很多钱 | 检查是否把"候选上限"调得很大；批量生产前先单关试跑 |

## 12. 名词对照（看到这些词不用慌）

| 词 | 意思 |
|---|---|
| 适配层 | 让工具读懂你游戏规则的一小段程序（AI 自动生成） |
| 门1 / 门2 | 自动检查 / 和真实游戏对拍的检查；门1 过了就能用 |
| 候选 | AI 的一次尝试结果；可以同时试几个，挑一个用 |
| 落盘 | 把关卡存成文件写进磁盘 |
| 难度 1/2/3 | 轻松 / 标准 / 烧脑，对应游戏里的小关、普通关、难关 |
| 玩法 | 一个游戏（比如 PiggyFarm） |
